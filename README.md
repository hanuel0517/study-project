# 청소년 스마트폰 사용과 학업 만족도 분석

## 1. 탐구 주제
청소년의 스마트폰 중독과 학업 집중도의 관계

## 2. 탐구 질문
청소년의 스마트폰 사용 시간이 길수록 학업 집중도는 낮아질까?

## 3. 주제를 고른 이유
청소년들은 스마트폰을 자주 사용하고, 공부할 때도 스마트폰을 확인하는 경우가 많다. 스마트폰 사용이 공부에 집중하는 데 어떤 영향을 주는지 궁금해서 이 주제를 선택했다.

## 4. 분석 방법
설문조사를 통해 스마트폰 사용 시간과 학업 집중도를 비교하고 어떤 관계가 있는지 알아본다

## 5. 데이터 수집 계획
- 출처: 직접 만든 설문조사
- 데이터 이름: 청소년 스마트폰 사용과 학업 집중도 조사
- 조사 연도: 2026년
- 조사 대상: 같은 반 친구들
- 조사 방법: 간단한 온라인 설문조사
- 조사 인원: 10명 정도
- 
## 6. 수집할 데이터
1. 하루 평균 스마트폰 사용 시간
2. 스마트폰을 가장 많이 사용하는 목적
3. 공부할 때 집중이 잘되는 정도

## 7. 데이터 이용 조건
개인정보를 수집하지 않고 익명으로 조사하며, 응답자의 동의를 받아 자료를 활용한다.

## 8. 다른 데이터 후보와 비교
청소년의 스마트폰 사용 실태에 관한 공공 통계도 생각했지만, 스마트폰 사용 시간과 학업 집중도를 함께 비교하기 위해 직접 설문조사를 선택했다.

## 9. 개인정보 보호
이름, 연락처 등 개인정보는 수집하지 않고 익명으로 조사한다.

## 10. 앞으로의 계획
친구들을 대상으로 설문조사를 진행하고, 수집한 데이터를 정리하여 스마트폰 사용 시간과 학업 집중도의 관계를 분석할 예정이다
