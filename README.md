# 청소년 스마트폰 사용과 학업 만족도 분석

## 1. 탐구 주제
청소년의 스마트폰 사용 목적과 학업 만족도의 관계

## 2. 탐구 질문
청소년의 스마트폰 사용 목적에 따라 학업 만족도는 정말 달라지는가?

## 3. 주제를 고른 이유
청소년들은 스마트폰을 자주 사용하지만 SNS, 게임, 영상 시청, 학습 등 사용하는 목적은 다양하다. 스마트폰 사용 목적에 따라 학업 만족도에도 차이가 있는지 궁금해서 이 주제를 선택했다.

## 4. 분석 방법
연관 분석을 활용하여 스마트폰 사용 목적과 학업 만족도 사이에 어떤 관계가 있는지 알아본다.

## 5. 데이터 수집 계획
- 출처: 직접 제작한 설문조사
- 데이터 이름: 청소년 스마트폰 사용 목적과 학업 만족도 조사
- 조사 연도: 2026년
- 조사 대상: 고등학생
- 조사 방법: 익명 온라인 설문조사

## 6. 수집할 데이터
1. 스마트폰을 주로 사용하는 목적
2. 하루 평균 스마트폰 사용 시간
3. 자신의 학업 만족도

## 7. 데이터 이용 조건
개인정보를 수집하지 않고 익명으로 조사하며, 응답자의 동의를 받아 자료를 활용한다.

## 8. 다른 데이터 후보와 비교
청소년 스마트폰 이용 실태에 관한 공공 통계도 후보로 생각했다. 하지만 스마트폰 사용 목적과 학업 만족도를 함께 비교할 수 있는 자료가 부족할 수 있어 직접 설문조사를 선택했다.

## 9. 개인정보 보호
이름, 연락처, 주소, 학번 등 개인을 알아볼 수 있는 정보는 수집하지 않는다.

## 10. 앞으로의 계획
설문조사를 진행하고 수집한 데이터를 정리한 뒤 스마트폰 사용 목적과 학업 만족도의 관계를 분석할 예정이다.
